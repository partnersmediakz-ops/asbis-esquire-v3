# Просто жить — Esquire × ASBIS, версия 3

Спецпроект о технологиях Apple для доступности. Третья версия на
React + Vite + Tailwind + GSAP.

## Запуск

    npm install
    npm run dev

## Идея версии

Первая версия — авторская editorial-режиссура, вторая — воспроизведение
видеопрототипа. Третья идёт от смысла материала: он о технологиях,
которые делают мир читаемым, поэтому сайт демонстрирует читаемость собой.

Отсюда три решения:

**Шрифт Atkinson Hyperlegible** создан Braille Institute для читателей с
ослабленным зрением: буквы различаются по форме, чтобы не путались
похожие пары.

**Панель читателя** вместо спрятанного переключателя. Выбор версии,
размер текста и озвучка собраны в один орган управления, доступный
всегда. Материал о доступности не должен прятать её настройки.

**Крупный базовый кегль**: текст читается без включения особого режима.

## Три версии материала

| Версия | Что даёт |
|---|---|
| Стандарт | обычное чтение |
| Аудиоверсия | озвучка с бегущей подсветкой по словам |
| Для слабовидящих | крупный кегль, простая раскладка |

Размер текста настраивается в любой версии: пять шагов от 100 до 200 %.
Фотографии при этом не растут — увеличивается только текст.

## Озвучка

37 фрагментов, синтезированных Silero локально. Плеер играет записи, а
при их отсутствии переключается на синтез в браузере. Латиница уходит в
синтез русской записью: Silero пропускает её молча.

Перегенерация — в проекте второй версии, скрипты там же.

## Ограничения

Настоящих видеороликов нет — в макете только статичные кадры. Тексты
попапа не переносились. Живую проверку с NVDA нужно провести руками.
